Projects

keep

Why I built it

My team runs several AI coding agents in the same repositories, and each one kept its own to-do list. Two agents would pick up the same task, or start on something that was still blocked.

What it does

A single Go binary that keeps one work queue in SQLite and serves it over MCP, so Claude Code and Codex claim work from the same list. Dependencies keep blocked items out of the ready list, and a local dashboard shows what each agent holds.

  • Go
  • SQLite
  • MCP

interlock

Why I built it

Running two agents in one checkout meant they overwrote each other's edits, and nobody found out until the tests broke. Nothing existing handled it across both Claude Code and Codex.

What it does

Hooks that make each agent hold the files it is editing. A second agent reaching for a held file is blocked before the edit lands and told who has it. A panel shows every hold, handoff and stopped collision.

  • Go
  • Claude Code hooks
  • Codex
